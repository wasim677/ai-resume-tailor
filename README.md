# AI Resume & Cover Letter Tailor

A fast CLI tool that analyzes a candidate's resume against any job description using OpenAI (`gpt-4o-mini`), outputting skill match analysis, an aligned professional summary, and a tailored cover letter draft.

## Features
- **Match Analysis:** Highlights overlapping skills and identifies missing requirements.
- **Custom Summary:** Generates an ATS-aligned summary targeting the job posting.
- **Draft Cover Letter:** Produces a concise, non-hallucinated cover letter draft.
